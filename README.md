# NP iConnect App: Website to Mobile App Redesign

View Prototype: [NP iConnect App on Figma](https://www.figma.com/design/drVGxVrzwZ35o3aDPREHYm/NP-iConnect-App?node-id=105-815&t=YwXZHeCqblnnuvjC-1)

A mobile app redesign concept for the Ngee Ann Polytechnic School of InfoComm Technology (NP ICT) website. This project transforms the existing website experience into a more accessible, student-friendly, and mobile-first application prototype.

## Project Overview

The NP ICT website contains important information for students, prospective students, and visitors. However, accessing this information through a website may not always feel convenient on mobile devices. This project redesigns the experience into a mobile app concept called NP iConnect, focusing on clearer navigation, improved content organisation, and a more engaging user experience.

The goal of this redesign is to make ICT-related information easier to browse, understand, and access on the go.

## Project Objectives

* Redesign the NP ICT website into a mobile-first app experience
* Improve navigation so users can find key information more quickly
* Organise content in a clearer and more user-friendly structure
* Create a visually consistent interface using an NP ICT-inspired colour theme
* Design an interactive prototype that demonstrates the main user flows
* Improve the overall accessibility and usability of ICT information for students

## Target Users

This redesign is mainly created for:

* Prospective students exploring NP ICT courses
* Current students looking for school-related information
* Parents who want to understand ICT programmes better
* Visitors interested in NP ICT events, achievements, and opportunities

## Key Features

* Clean and modern mobile interface
* Homepage with quick access to important ICT information
* Course information pages
* Student life and event sections
* Simple navigation structure
* Interactive mobile prototype
* Consistent visual design based on NP ICT branding

## Features

### Programme Discovery
Explore NP ICT’s full-time and part-time programmes, view course details, and compare available pathways.

### Programme Match Quiz
A short guided quiz that helps users who are unsure which ICT programme suits them best.

### News & Announcements
A central feed for school updates, announcements, and ICT-related news.

### Events & Registration
Users can browse upcoming NP ICT events, view event details, register for events, and track registered or past events.

### Connect Community Feed
A social community space where alumni, industry partners, prospective students, and parents can share stories, ask questions, and engage with one another.

### Community Q&A Threads
Users can ask questions and receive helpful responses from alumni, seniors, and the wider NP ICT community.

### Campus Map & Directions
Allows users to search for campus locations, view map details, zoom in or out, and navigate around campus.

### NP Assistant Chatbot
A chatbot experience that helps users ask quick questions about programmes, events, locations, and school information.

### About NP ICT
Showcases the School of ICT, including reasons to choose NP ICT, testimonials, and industry partnerships.

### User Support & More
Includes contact options, feedback, help and support, settings, privacy information, terms of use, and reporting channels.


## Design Focus

The design focuses on creating a user experience that is:

* Mobile-friendly: Optimised for users browsing on their phones
* Clear: Information is organised into easy-to-understand sections
* Accessible: Important content is easier to locate
* Consistent: Colours, spacing, and components are kept visually aligned
* Engaging: The app feels more interactive and modern compared to a standard website

## Project Process

### 1. Research and Understanding

I reviewed the existing NP ICT website to understand its content structure, target users, and the type of information users would commonly look for.

### 2. Information Architecture

The website content was reorganised into a mobile app structure so that users can navigate through information more easily.

### 3. Wireframing

Initial layouts were created to plan the app screens, user flow, and placement of key content.

### 4. UI Design

A polished interface was designed using an NP ICT-inspired purple colour theme, clean spacing, readable text, and consistent components.

### 5. Prototyping

The final screens were connected in Figma to create an interactive mobile app prototype.
